SVG MORPHEUS TS 2.0

让 SVG 图标平滑变形

把图标放在带 id 的 SVG 分组中，创建实例，再调用 to() 切换目标。支持浏览器控制器与可独立使用的纯函数内核。

随时改变目标

连续点击时，从当前画面继续几何与颜色过渡。

颜色与渐变一起变化

保留多色、透明度、孔洞及绘制组的合成关系。

浏览器与独立 core

TypeScript、ESM/CJS，无运行时依赖；core 支持 Node/SSR。 

npm install svg-morpheus-ts@^2.0.0

最小用法

每个 g 是一个图标；id 是切换时使用的名称。 

<svg id="icons" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">
  <g id="menu"><path d="M4 6H20M4 12H20M4 18H20" /></g>
  <g id="close"><path d="M6 6L18 18M18 6L6 18" /></g>
</svg>
import SVGMorpheus from 'svg-morpheus-ts'

const icon = new SVGMorpheus('#icons', {
  iconId: 'menu', duration: 750, rotation: 'none',
})
icon.to('close')
// Cleanup: icon.destroy()

接入项目 SVG

不用重画图标。准备一个固定的 SVG 容器，把已有 SVG 字符串或元素通过 addIcon(id, svg) 注册；项目状态变化时调用 to(id)。id 由你命名，不是文件路径。 

<svg id="project-icon" viewBox="0 0 24 24" role="img" aria-label="Icon"></svg>
<button id="show-a">A</button>
<button id="show-b">B</button>

方式一：Vite 导入已有文件

?raw 返回 SVG 文件文本，不是 URL，也不是 Vue/React 组件。把路径换成项目已有的两个 .svg 文件；以下代码在页面挂载后执行。 

import SVGMorpheus from 'svg-morpheus-ts'
import menuSVG from './assets/menu.svg?raw'
import closeSVG from './assets/close.svg?raw'

const morph = new SVGMorpheus('#project-icon', {
  duration: 600, rotation: 'none',
})
morph.addIcon('menu', menuSVG)
morph.addIcon('close', closeSVG)
morph.set('menu')

document.querySelector('#show-a').onclick = () => morph.to('menu')
document.querySelector('#show-b').onclick = () => morph.to('close')
// Cleanup: morph.destroy()

方式二：普通网页加载 SVG URL

addIcon 不负责下载 URL；先 fetch 文件文本。无构建工具时，将发布包的 dist/index.js 复制到站点的 vendor/svg-morpheus-ts/index.js，在 script type="module" 中运行以下代码；使用部署后可访问的 SVG 地址。 

import SVGMorpheus from './vendor/svg-morpheus-ts/index.js'

const sources = { menu: './icons/menu.svg', close: './icons/close.svg' }
const files = await Promise.all(Object.entries(sources).map(async ([id, url]) => {
  const response = await fetch(url)
  if (!response.ok) throw new Error(`${url}: ${response.status}`)
  return [id, await response.text()]
}))
const morph = new SVGMorpheus('#project-icon', { rotation: 'none' })
for (const [id, svg] of files) morph.addIcon(id, svg)
morph.set('menu')
document.querySelector('#show-a').onclick = () => morph.to('menu')
document.querySelector('#show-b').onclick = () => morph.to('close')
// Cleanup: morph.destroy()

已有内联 SVG 元素也可以直接传给 addIcon，例如 morph.addIcon('logo', document.querySelector('#source-logo'))。框架项目只保留一个预览 SVG 实例，在挂载后创建控制器，在卸载时 destroy()；不要每次切换都重建容器。

用自己的 SVG 试一下

粘贴两份完整 SVG，或选择两个本地 .svg 文件。文件只在当前浏览器读取，不上传到服务器。点击“注册两份 SVG”后，用 A/B 连续切换；示例按钮可恢复本地文件或 Iconify 数据。

只使用可信的 SVG。图标应包含实际路径或基础图形；img、CSS mask、字体图标和 use/symbol 引用需要先取得其原始 SVG 数据。蒙版、滤镜、裁切和依赖外部 CSS 的绘制不属于自动支持范围。

接入 Iconify

可以使用 Iconify 的本地图标集合或已取得的图标数据，不需要先渲染 Iconify 组件再读取 DOM。用官方 Utils 解析集合默认尺寸、别名、旋转和翻转，再把转换出的 SVG 注册到同一个变形实例。 

npm install @iconify/utils @iconify-json/lucide

下面继续使用上面的 project-icon 和 A/B 按钮。getIconData 的名称不带集合前缀；注册 id 则与项目状态使用的 lucide:menu、lucide:x 保持一致。 

import SVGMorpheus from 'svg-morpheus-ts'
import { icons } from '@iconify-json/lucide'
import { getIconData, iconToSVG, iconToHTML, replaceIDs } from '@iconify/utils'

function svgFor(name) {
  const data = getIconData(icons, name)
  if (!data) throw new Error(`Unknown icon: lucide:${name}`)
  const { attributes, body } = iconToSVG(data)
  return iconToHTML(replaceIDs(body), attributes)
}
const morph = new SVGMorpheus('#project-icon', { rotation: 'none' })
for (const name of ['menu', 'x']) morph.addIcon(`lucide:${name}`, svgFor(name))
morph.set('lucide:menu')
document.querySelector('#show-a').onclick = () => morph.to('lucide:menu')
document.querySelector('#show-b').onclick = () => morph.to('lucide:x')
// Cleanup: morph.destroy()

如果项目已有 IconifyIcon 格式的 { body, width, height, ... } 数据，直接传给 iconToSVG 即可，不需要安装整个图标集合。Iconify API 返回的集合 JSON 也可以交给 getIconData 处理。

svg-morpheus-ts 不会根据 prefix:name 自动联网取图，也不强制依赖 Iconify。集合导入及按需提取由项目构建工具负责；本站演示只打包三枚 Lucide 图标。包含不受支持的蒙版或滤镜的 Iconify 图标不能直接变形。

交互示例

点击目标名称切换图标。动画过程中也可以选择另一个目标。

演示通过 easings 注册 springProgress() 预设；控制器的 easing 参数始终使用名称。 

import { easings, springProgress } from 'svg-morpheus-ts'
easings['spring-snappy'] = t => springProgress(t, 'snappy')
icon.to('close', { easing: 'spring-snappy', duration: 750 })

API

构造器接收 SVG 元素、选择器或 object 元素。下面是常用配置与实例方法。

配置 默认值 含义
iconId — 初始图标的分组 id；省略时显示最后一个分组。
duration 750 毫秒；0 立即切换。
easing quad-in-out 缓动函数名称；可通过 easings 注册自定义函数。
rotation clock 附加旋转：clock、counterclock、none、random。none 不禁止形状自身的转向。
reducedMotion user user 遵循系统；always 总是跳过动画；never 始终播放。
方法 含义
to(id, options?, callback?) 变形到目标，单次 options 覆盖默认设置。
set(id) 立即切换，不启动动画。
cancel(finish = false) 停止在当前画面；finish=true 则完成到目标。
addIcon(id, svg) 添加或替换图标，支持 SVG 字符串和元素。
removeIcon(id) 删除图标，返回是否找到该 id。
getIconIds() 获取当前图标名称。
destroy() 停止动画、清理监听器；销毁后不可继续使用。

无 DOM 内核

Node、SSR 或自定义渲染器可使用 core 入口。调用方准备相同坐标系的路径并负责逐帧显示；内核不会访问 document。 

import { createMorphPlan, springProgress } from 'svg-morpheus-ts/core'

const plan = createMorphPlan(
  [{ d: 'M4 6H20M4 12H20M4 18H20', allowReverse: true, draw: true }],
  [{ d: 'M6 6L18 18M18 6L6 18', allowReverse: true, draw: true }],
)
const paths = plan.frame(springProgress(0.5, 'snappy'))

描边路径可设置 draw: true，使新增或消失的轮廓沿原路径画出/收回。填充路径不应开启；已有对应轮廓仍使用几何变形。

颜色与渐变

createPaintPlan() 插值绘制属性，renderPaintFrame() 生成 SVG 内容。支持多色、透明度与线性/径向渐变；不兼容的渐变使用交叉过渡。groups 表示共同合成的透明度组，不能提前乘入每条路径。 

import { createPaintPlan, renderPaintFrame } from 'svg-morpheus-ts/core'
const paint = createPaintPlan(
  [{ attributes: {}, fill: '#ff000080' }],
  [{ attributes: {}, fill: '#0066ff' }],
)
const body = renderPaintFrame(paths, paint.frame(0.5), 'unique-icon-id')

currentColor 和 CSS 变量保留给浏览器解析。需要数值颜色插值时，先由调用方解析成具体颜色。

实验区 · 不包含在 npm 发布包中

下面展示共边与中心线的研究原型；正式使用请从控制器或 core API 开始。人工中心线不代表任意填充 SVG 都能自动按线条收回。

眼睛切换：固定共同区域

消失的弧线沿自身中心线逐段收回，保持原来的半径、线宽和矢量边缘，共同区域不动。拖动进度可查看移动的线端，也可切换旧的缩小、淡出方案对比。

填充图标没有保留绘制中心线。本例补充了四条人工中心线，引导差异片段按可见弧长收回；不是从任意填充 SVG 自动推断。尚未接入正式 core。

保留 AB，只改变 BC

绿色共边始终不动，蓝色差异段沿原轨迹收回或展开。支持直线、曲线及反向路径；这是开放描边实验，不适用于填充面与孔洞。

绿色：保留部分 AB；蓝色：变化部分 BC。拖动进度可逐帧检查。播放时长 1.6 秒。

独立研究 · 不进入正式动画

公共边界研究

这对眼睛图标没有相同的完整路径。实验按位置和切线方向查找近似重合的曲线片段，并用绿色高亮。

比例只表示采样边界长度覆盖，不是面积或语义相似度。尚未处理轮廓拆分、合并与孔洞的动画对应，不能直接把检测片段锁定后套入正式变形。
